## Problem

Vion Inovation needed backend architectures that could support AI-based products as they moved from idea to implementation — decisions made early here directly shaped how fast the AI-facing features could ship later.

## My role

I defined the technical architecture for these products, implemented the APIs behind them, and supported the broader team as AI-based features were developed on top of that foundation.

## How I approached it

Architecture decisions were made with the AI integration in mind from the start — API boundaries designed so AI-based features could be added and iterated on without reworking the core backend each time.

## What I'm learning

This is the longest-running relationship in my experience so far, which has meant living with my own early architectural decisions long enough to see which ones actually held up — a different kind of feedback loop than a short project gives you.
